# 🎥 Renix Screen Recorder

**Renix Screen Recorder** est une application open-source moderne pour enregistrer votre écran, avec une qualité professionnelle, une interface intuitive et des fonctionnalités avancées comme la sélection de zone, la capture audio et les annotations.

---

## 🧩 Fonctionnalités

- 🖥️ Enregistrement de :
  - L’écran complet
  - Une fenêtre spécifique
  - Une zone sélectionnée
- 🎙️ Capture du micro et/ou audio système
- 📷 Option webcam (activable/désactivable)
- 🖱️ Affichage des clics souris avec effet visuel personnalisable
- ✏️ Annotations (bientôt disponibles)
- ⌨️ Raccourcis clavier activables
- 🔄 Arrêt automatique de l’enregistrement
- 🎞️ Export en formats WebM, MP4, etc.
- 💾 Possibilité d'enregistrer les paramètres

## ⚙️ Stack technique

- **React + TypeScript**
- **Tailwind CSS** pour le design UI
- **Lucide-react** pour les icônes
- **MediaRecorder API** pour l’enregistrement natif
- **Electron** pour la version desktop *(à venir)*

## 🧪 Lancer le projet en local

```bash
# Cloner le dépôt
git clone https://github.com/ton-utilisateur/renix-screen-recorder.git
cd renix-screen-recorder

# Installer les dépendances
npm install

# Démarrer le serveur local
npm run dev

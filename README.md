Here's the project specification for a desktop screen recording application similar to Filmora, using Electron.js, in English:

## Functional Specifications

### Screen Recording
- Capture full screen, custom area, or specific window
- Simultaneous recording of multiple monitors
- Adjustable frame rate and quality settings (Good, Better, Best)
- Scheduled automatic recordings

### Audio Capture
- Simultaneous system sound and microphone recording
- Flexible audio source selection

### Webcam
- Picture-in-Picture webcam video integration
- Resizable and repositionable webcam window

### User Interface
- Intuitive interface inspired by Filmora
- Control buttons: Start, Pause, Stop recording
- Customizable keyboard shortcuts (e.g., F9 for start/stop, F10 for pause/resume)

### Basic Editing
- Add visual effects for mouse clicks
- Insert text and annotations

### Export
- Export to common video formats (MP4, AVI, etc.)
- Compression settings to optimize file size

## Technical Specifications

### Technology
- Electron.js for cross-platform development (Windows, macOS, Linux)
- Angular for user interface
- TypeScript for application logic

### Architecture
- Electron main process for application management
- Renderer process for user interface
- Node.js modules for system functionality access

### Performance
- Optimization for minimal CPU and GPU usage
- Efficient memory management for long recordings

### Security
- Secure management of screen, microphone, and webcam access permissions
- Encryption of local recordings

## Design and Usability

- Modern and clean interface inspired by Filmora
- Dark theme by default with light theme option
- Intuitive layout of controls and options

This project specification outlines the foundation for a robust and user-friendly screen recording application, similar to Filmora, using modern web technologies and Electron.js for cross-platform distribution.
